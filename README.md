# Word List Study

CSVの単語リストを使って学習する、ブラウザ上で動くアプリです。静的ファイルで構成され、Node.jsの実行環境を利用者側へ要求しません。

## ファイル

- `index.html`：画面、操作、ブラウザ保存との接続
- `study-core.js`：学習状態、ページモデル、履歴、CSV/GPT処理などの共有ロジック。`index.html`から読み込まれるため、アプリの起動・公開には必須です。
- `sample.csv`：動作確認用のサンプル
- `docs/study-system-design.md`：状態モデルと処理フローの詳細
- `test/study-core.test.js`：Node.js標準テスト

## 起動

リポジトリ内の`index.html`をブラウザで開くか、リポジトリのルートで簡易HTTPサーバーを起動します。たとえばPython 3がある場合：

```sh
python3 -m http.server 8000
```

その後、`http://localhost:8000/`を開きます。`index.html`と`study-core.js`は同じ公開ルートに置いてください。ブラウザのlocalStorageに単語・設定・学習状態が保存されます。

開発者はNode.jsでテストを実行できます。

```sh
node --test
```

## CSVの読み込み

ホーム画面または設定画面からCSVを選びます。新しい形式は`id,question,answer`ヘッダーを使い、`explanation`列は任意です。従来形式の`id,word,meaning`も読み込めます。IDは空でなく、リスト内で一意である必要があります。`sample.csv`を例として利用できます。

## 学習の基本操作

1. ホーム画面でCSVを登録し、「学習する」を選択します。
2. ページの単語はカーテンで覆われます。境界のドラッグハンドルを上下して順に開示します。
3. カーテンを通過した個別マスクは意味欄を押して開けます。未開示中の評価ボタンは無効です。開示時には設定されたデフォルト評価が入り、開示後は○/×を切り替えられます。
4. 「続きに戻る」は学習先端へカーテンを戻します。カーテンロックは10問表示では使えず、20問以上の表示で利用できます。ロック解除は境界を維持します。
5. 表示問題数の変更では学習中の未確定評価を確定し、開示先端を含むページで新しい学習セッションを開始します。

詳しいページ遷移、保存状態、カーテン動作は[学習システム設計書](docs/study-system-design.md)を参照してください。

## GPT連携

GPT学習モーダルで問題数と開始位置を選び、「プロンプトを発行」します。発行されたプロンプトを確認・コピーするか、「ChatGPTで開く」を選びます。ChatGPTで学習した後、返された結果JSONをアプリの「学習結果を登録する」に貼り付けるか、結果リンクを開いて登録欄へ読み込み、内容を確認して登録します。結果の登録・ページ移動・重複登録確認はアプリの既存フローに従います。

## GitHub Pages

静的ホスティングで利用できます。GitHub Pagesをブランチから公開する場合は、リポジトリ設定で対象ブランチとルートを選び、`index.html`と`study-core.js`を同じ公開ルートに配置してください。デプロイ方式やGitHub Pagesの設定はリポジトリ側の公開設定に従います。
